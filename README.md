# macOS scripts

> [!Important]
> The UnityModManager installer has moved to its own repository: [sbrothers7/UMMInstall](https://github.com/sbrothers7/UMMInstall). Please update any bookmarks or links — the old `UMMInstall/` directory in this repo is no longer maintained.

Clone script(s) with git:

``` sh
git clone "https://github.com/sbrothers7/scripts/script_example.sh"
```

Run once per script:

``` sh
chmod u+x script_example.sh
sh script_example.sh
```

# macOS 스크립트

> [!Important]
> 얼불춤 모드 딸깍설치기는 별도의 repo로 이전되었습니다: [sbrothers7/UMMInstall](https://github.com/sbrothers7/UMMInstall). 북마크와 링크를 새 repo로 업데이트해 주세요 — 이 저장소의 `UMMInstall/` 디렉토리는 더 이상 관리되지 않습니다.

`git`으로 스크립트를 복제:

``` sh
git clone "https://github.com/sbrothers7/scripts/script_example.sh"
```

스크립트 실행:

``` sh
chmod u+x script_example.sh
```
